# Reasoning-Aware-Perceptual-Framework-RAPF-
The Reasoning-Aware Perceptual Framework (RAPF) is an open-set wild plant segmentation model using a closed-loop perception-reasoning structure. It fuses CLIP-DINOv2 features, applies HQ-SAM for masking, and uses Dempster-Shafer reasoning with botanical knowledge to identify known and unknown species reliably in complex natural scenes.
